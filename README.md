# Urban Explorer — An Interactive Product Pitch

**Exploring how game mechanics could make everyday city walks more engaging.**

This repository contains a **15-slide interactive web pitch deck** for Urban Explorer, a concept for game-based city discovery. It is a product exploration and presentation prototype, **not a released mobile app**.

## The opportunity

People can move through familiar streets without noticing the stories, places, and possibilities around them. Urban Explorer explores a playful alternative: discover nearby points of interest by walking, unlocking short stories, and making exploration feel rewarding.

## The proposed experience

The pitch deck introduces:

- **A fog-of-war map** to make unexplored places visible as opportunities.
- **Curated story points of interest** that encourage local discovery.
- **A lightweight interface** focused on the next place to explore.
- **A core loop:** spot a nearby quest → walk to it → unlock a story and points → continue exploring.
- **A product and business hypothesis** covering users, partners, and a potential multi-sided model.

These are design concepts and hypotheses presented in the deck, not claims about completed app functionality or market validation.

## What this repository demonstrates

- **Strategy:** translating an opportunity into a value proposition, user experience, and business-model hypotheses.
- **Product thinking:** designing a simple engagement loop and evaluating where motivation comes from.
- **Web implementation:** building a navigable, visual storytelling experience as a single-page HTML presentation.

## What's in the code

- `index.html` — interactive pitch deck with layout, transitions, visual presentation, and concept storytelling.

## View locally

Open `index.html` in a web browser. The deck uses externally hosted Google Fonts for some typography.

## Project stage

**Concept / pitch prototype.** The interactive presentation illustrates the proposed product; it does not implement location tracking, a real-world quest engine, or an operational mapping service.
